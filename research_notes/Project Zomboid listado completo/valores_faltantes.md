# Project Zomboid: valores numéricos que faltaban

Fuentes principales:
- **[DEC-B42]**: código Java decompilado de B42 (~42.19/42.20), repo `geromet/PZJavaDocs`: https://github.com/geromet/PZJavaDocs/tree/main/sources/zombie
- **[LUA-B42]**: Lua vanilla B42.20.2, repo `Project-Zomboid-Community-Modding/ProjectZomboid-Vanilla-Lua`: https://github.com/Project-Zomboid-Community-Modding/ProjectZomboid-Vanilla-Lua (`shared/Sandbox/Apocalypse.lua`, `shared/defines.lua`)
- **[WIKI]**: pzwiki.net, leído con Wayback (`https://web.archive.org/web/2025id_/https://pzwiki.net/wiki/<Página>`)

Convención de tiempo en el código: `GameTime.getMultiplier()` suma unas **60 unidades por segundo real** a velocidad x1 (`fpsMultiplier = 60/fps`, en `FPSTracking.java`). Las tasas "/s" de abajo salen de multiplicar por 60. Son derivadas del código, no medidas en el juego.
